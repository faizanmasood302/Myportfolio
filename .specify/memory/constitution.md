# Project Constitution: Personal Portfolio CLI Tool

## 1. Vision and Mission
The Personal Portfolio CLI Tool is designed to empower Muhammad Faizan, an AI/ML Engineer, to deliver a memorable first impression to senior recruiters and CTOs within 8 seconds of landing. It combines advanced dark-editorial aesthetics with cyber-refined motion-forward design to showcase technical expertise and creative technologist capabilities.

## 2. Core Principles
* **Performance First**: MUST achieve Lighthouse scores ≥ 95 across all categories. FCP MUST be ≤ 1.2s and LCP ≤ 2.5s. Animations MUST prioritize transform and opacity to avoid layout shifts.
* **Aesthetic Excellence**: MUST adhere to the defined "Dark Void" palette and "Syne/DM Mono/Fraunces" typography. Design MUST be visually appealing, substantially complete, and functional from the first prototype.
* **Seamless Interactivity**: MUST provide rich micro-interactions (magnetic buttons, 3D tilt, custom cursor) while respecting `prefers-reduced-motion` settings. Interactivity MUST feel modern and "alive."
* **Recruiter-Centric UX**: MUST prioritize accessibility to key information (resume, contact, social proof) and provide clear live project demos. UX MUST be optimized for a quick "8-second" impact assessment.
