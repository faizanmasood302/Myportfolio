# Quickstart: Personal Portfolio CLI Tool

## Installation
```bash
npm install -g @faizan/portfolio-cli
```

## Usage

### 1. Initialize Project
```bash
portfolio init my-portfolio
cd my-portfolio
```

### 2. Add Content
```bash
portfolio add project  # Interactive prompt
portfolio add skill    # Interactive prompt
```

### 3. Development
```bash
npm run dev
```

### 4. Build & Deploy
```bash
portfolio build
portfolio deploy
```

## Local Configuration
Edit `portfolio.config.ts` to customize your personal details and theme tokens.
